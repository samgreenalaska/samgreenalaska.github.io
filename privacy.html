Privacy

Privacy policy for Sam Green's personal Google apps

This policy covers two personal tools, gmail-mcp and photo-frame-tv. Each connects Sam Green's own Google accounts to software he runs himself. Neither has other users, neither is offered as a product, and no one else can sign in to them.

gmail-mcp

What it accesses. The application requests the Google https://mail.google.com/ scope for four Gmail accounts, all belonging to the operator. That scope allows reading, composing, sending, labelling and deleting mail. The tool uses it to search threads, read message bodies, list and change labels, and create drafts.

Where the data goes. Mail is fetched from the Gmail API on demand by a server the operator runs on his own cloud instance. It is passed straight back to whichever client asked for it. In normal use that client is Claude, an AI assistant made by Anthropic, so message content included in a request reaches Anthropic and is handled under Anthropic's own privacy terms. Mail is not sent anywhere else.

What is stored. The server stores one Google OAuth refresh token per account, so it can reconnect without a fresh sign-in. It also stores the OAuth client credentials for the project. Both are kept on disk with owner-only permissions, and every request to the server must carry a shared secret. Message content is not stored. Nothing is written to a database, a log of message bodies, or a cache that outlives the request.

photo-frame-tv

What it accesses. The application requests the Google Photos photoslibrary.appendonly scope for one account belonging to the operator. That scope only allows adding photos and creating albums. It cannot read, download, change or delete anything already in the library.

What it does. It copies photos from one album on the operator's home storage to one Google Photos album the application created, so a Google TV can show them as a screensaver. Each photo is resized before upload. Photos are only ever added, never removed.

Where the data goes. Photos travel from the operator's home storage, through a computer he owns, to Google Photos. They are not sent anywhere else.

What is stored. That computer stores the OAuth refresh token, the OAuth client credentials, and a list pairing each uploaded photo with the ID Google assigned it. The list is also copied to the operator's private file server, so a lost copy cannot cause duplicate uploads. Nothing read from Google is stored, because the scope allows nothing to be read.

Sharing

No data from either application is sold, shared, published, or used for advertising, and no third party is given access to it beyond what is described above.

Analytics

This page carries no analytics. Other pages on this site use PostHog to count visits, and that tracking never touches mail, photos, or either application.

Revoking access

Access can be withdrawn at any time from the Google Account permissions page. Removing an application there invalidates its tokens immediately. Deleting the stored token files has the same effect from the other direction.

Other apps

Limited use

Use of information received from Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements.
