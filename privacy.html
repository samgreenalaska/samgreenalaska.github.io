Privacy

Privacy policy for gmail-mcp

gmail-mcp is a personal tool. It connects Sam Green's own Gmail accounts to a server he operates himself. It has no other users, it is not offered as a product, and no one else can sign in to it.

What it accesses

The application requests the Google https://mail.google.com/ scope for four Gmail accounts, all belonging to the operator. That scope allows reading, composing, sending, labelling and deleting mail. The tool uses it to search threads, read message bodies, list and change labels, and create drafts.

Where the data goes

Mail is fetched from the Gmail API on demand by a server the operator runs on his own cloud instance. It is passed straight back to whichever client asked for it. In normal use that client is Claude, an AI assistant made by Anthropic, so message content included in a request reaches Anthropic and is handled under Anthropic's own privacy terms.

Mail is not sent anywhere else. It is not sold, shared, published, or used for advertising, and no third party is given access to it.

What is stored

The server stores one Google OAuth refresh token per account, so it can reconnect without a fresh sign-in. It also stores the OAuth client credentials for the project. Both are kept on disk with owner-only permissions, and every request to the server must carry a shared secret.

Message content is not stored. Nothing is written to a database, a log of message bodies, or a cache that outlives the request.

Analytics

This page carries no analytics. Other pages on this site use PostHog to count visits, and that tracking never touches mail data or the application.

Revoking access

Access can be withdrawn at any time from the Google Account permissions page. Removing the application there invalidates its tokens immediately. Deleting the stored token files on the server has the same effect from the other direction.

Limited use

Use of information received from Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements.
